Privacy policy

Last updated 3 October 2026.

Newsstand is a personal tool with a single user, its owner. It has no other users and does not collect data from anyone.

What Google data it accesses

With the owner's authorisation, Newsstand uses the Google Drive API to upload PDF files into one folder in the owner's Drive, create view links for those files, check the remaining storage quota, and delete files it uploaded once they are seven days old. It does not read, index or modify any other files.

How the data is stored and shared

The OAuth token is stored only on the owner's home server, readable by that account alone. No Google user data is sold, shared with third parties, used for advertising, or used to train AI or machine-learning models. Links to uploaded files are emailed only to recipients the owner has chosen.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Newsstand's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
